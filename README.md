# ChatIF
Site para resolver duvidas de discentes, através de um banco de 
perguntas pré cadastradas pelos admins (professores e desenvolvedores do ChatIF),
para encontrar a pergunta feita pelo usuarioa, sera utilizado
um algoritimo de busca, focado em filtrar palavras chaves

**Camada**            **Tecnologia**
Hospedagem       InfinityFree (primeiras versões)
Front-end        HTML5, CSS3, JavaScript e Bootstrap 5
Back-end         PHP 8
Banco de Dados   MySQL
vercionamento    Git e GitHub
IDE Visual       Studio Code
Prototipação     Figma
Testes da API    Postman

**Justificativa**

**InfinityFree:**
hospedagem gratuita utilizada durante o desenvolvimento e validação das primeiras versões do sistema.
**HTML5:**
estruturação das páginas.
**CSS3:**
estilização e responsividade da interface.
**JavaScript:**
interatividade da aplicação e comunicação com o back-end.
**PHP 8:**
implementação da lógica de negócio e da API do sistema.
**MySQL:**
armazenamento das informações do sistema.
**Git e GitHub:**
controle de versão e gerenciamento do código-fonte.
**Visual Studio Code:**
ambiente de desenvolvimento utilizado pela equipe.
**Figma:**
criação dos protótipos das interfaces.
Postman:
testes e validação dos endpoints da API.
