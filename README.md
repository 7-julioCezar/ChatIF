# ChatIF
Site para resolver duvidas de discentes, através de um banco de 
perguntas pré cadastradas pelos admins (professores e desenvolvedores do ChatIF),
para encontrar a pergunta feita pelo usuarioa, sera utilizado
um algoritimo de busca, focado em filtrar palavras chaves

| **Camada**         | **Tecnologia**                    |
| ------------------ | ----------------------------------|
| **Hospedagem**     | InfinityFree (primeiras versões)  |
| **Front-end**      | HTML5, CSS3 e JavaScript          |
| **Back-end**       | PHP 8                             |
| **Banco de Dados** | MySQL                             |
| **Versionamento**  | Git e GitHub                      |
| **IDE**            | Visual Studio Code                |
| **Prototipação**   | Figma                             |
| **Testes da API**  | Postman                           |


| **Tecnologia**         | **Justificativa**                                                                                     |
| ---------------------- | ----------------------------------------------------------------------------------------------------- |
| **InfinityFree**       | Hospedagem gratuita utilizada durante o desenvolvimento e validação das primeiras versões do sistema. |
| **HTML5**              | Responsável pela estruturação das páginas da aplicação.                                               |
| **CSS3**               | Utilizado para estilização e responsividade da interface.                                             |
| **JavaScript**         | Responsável pela interatividade da aplicação e comunicação com o back-end.                            |
| **PHP 8**              | Implementação da lógica de negócio, autenticação, API e processamento das requisições do sistema.     |
| **MySQL**              | Armazenamento e gerenciamento das informações do sistema.                                             |
| **Git e GitHub**       | Controle de versão, gerenciamento do código-fonte e colaboração entre os desenvolvedores.             |
| **Visual Studio Code** | Ambiente de desenvolvimento (IDE) utilizado pela equipe para implementação e manutenção do código.    |
| **Figma**              | Criação dos protótipos e do design das interfaces do sistema.                                         |
| **Postman**            | Testes, validação e depuração dos endpoints da API durante o desenvolvimento.                         |
